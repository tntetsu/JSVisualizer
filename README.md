# JSVisualizer

> 🌐 [日本語版](README.md) | 🚀 Live Demo (準備中)

JavaScript プログラムの実行過程をインタラクティブに可視化する教育用 Web アプリケーションです。

式・文・関数呼び出しの各粒度でステップ実行しながら、**13 種類の可視化ビュー**でプログラムの動作（時間の経過とともにメモリの内容がどう変化するか）を直感的に理解できます。

## 特徴

### 多彩な可視化ビュー

| カテゴリ | ビュー | 説明 |
|----------|--------|------|
| **テキスト系** | アニメーション付きトレース表 | ステップごとに行が追記されるトレース表 |
| | 静的トレース表 | 全ステップを一覧できる表 |
| | スコープ・変数ビュー | ネスト枠でスコープチェーンを表現 |
| | コールスタックビュー | 関数呼び出しのスタックフレーム |
| **グラフ系** | 棒グラフアニメーション | 数値変数・配列の変化を棒グラフで |
| | 色付き箱アニメーション | 配列要素を色付き箱でインデックス付き表示 |
| | 変数の時系列グラフ | 変数値の推移を折れ線グラフで |
| | 実行頻度ヒートマップ | 各行の実行回数を色の濃さで表現 |
| **構造系** | 再帰ツリービュー | 再帰呼び出しを木構造で可視化 |
| | スコープ・ライフタイムタイムライン | 変数の生存期間をガントチャートで |
| | 制御フロービュー | if/for をフローチャートで可視化 |
| | メモリモデルビュー | スタック/ヒープの領域確保・解放 |
| | オブジェクトグラフ | オブジェクト・配列の参照関係をグラフで |

### ステップ実行の粒度

| 粒度 | 説明 |
|------|------|
| **式評価** | 全 AST ノードの評価（最細粒度） |
| **文評価** | 文単位（サブ式をスキップ） |
| **関数呼び出し** | 関数呼び出しをひとまとまりに |
| **人にやさしい単位** | 代入・条件判定・ループ更新など意味ある変化点のみ |

### その他

- **ステップバック対応** — 過去のステップに戻れる（O(1)）
- **サンプルコード内蔵** — バブルソート、フィボナッチ、二分木など
- **カスタムコード対応** — 自分で書いた JavaScript を貼り付けて実行
- **ビュー同時表示** — 複数ビューを並べて比較可能

## インストール

```bash
git clone https://github.com/tntetsu/JSVisualizer.git
cd JSVisualizer
npm install
```

> JSInterpreter が `../JSInterpreter` に存在する必要があります。

```bash
# JSInterpreter が未取得の場合
cd ..
git clone https://github.com/tntetsu/JSInterpreter.git
cd JSVisualizer
```

## 背景・動機

プログラミング教育において、学生がバグの修正に苦労する主な原因は「プログラムの動作の理解不足」です。紙や静的なスライドでは動作が伝わりにくく、既存のトレースツール（Algorithm Visualizer、Python Tutor など）は可視化専用コードの埋め込みが必要だったり、表示が見にくいという問題があります。

JSVisualizer は **汎用の JavaScript インタープリタ**を内蔵することで、任意のコードを貼り付けるだけで多彩な可視化を提供します。
