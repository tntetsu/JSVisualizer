## JSVisualizer の操作方法

### 画面構成

```
┌─────────────────┬──────────────────────────────────────┐
│                 │ [State] [Trace] [Rec.Tree] [ExecTrace] … │
│   ソースコード   │                                          │
│   （左ペイン）   │        可視化ビュー（右ペイン）           │
│                 │                                          │
├─────────────────┴──────────────────────────────────────┤
│                     コンソール出力                          │
├────────────────────────────────────────────────────────┤
│  ⏮  ◀◀Stmt  ◀Expr  ▶Expr  ▶▶Stmt  ⏭  ─スライダー─  │
│      ⏪Func  ◁Human  ▷Human  ⏩Func                     │
└────────────────────────────────────────────────────────┘
```

### Step 1: コードを実行する

1. 画面上部のドロップダウン（「— Sample —」）からサンプルを選ぶ
2. **▶ Run** ボタンをクリック  
   → 左ペインにコードが表示され、ステップボタンが有効になります

### Step 2: ステップを進める

フッターのボタンで実行を 1 ステップずつ追えます。

| ボタン | キー | 進み方 |
|--------|------|--------|
| **▷ Human** | `h` | **おすすめ**: 変数の値が変わる・条件が評価されるなど「意味のある変化」だけに進む |
| **▶ Expr** | `→` | 細かく 1 式ずつ進む |
| **▶▶ Stmt** | `v` | 文（行）単位で進む |
| **⏩ Func** | `f` | 関数呼び出し単位で進む |
| **⏭** | `End` | 最後まで一気に進む |
| **⏮** | `Home` | 先頭に戻る |

> **ヒント**: まずは `h`（Human）キーで進めながら、右ペインの変数の変化を観察してみてください。

### Step 3: ビューを切り替える

右ペインのタブ（数字キー 1〜9 でも切り替え可）でさまざまな角度からコードを観察できます。

| タブ名 | 特徴 |
|--------|------|
| **State** | 現在の変数値とコールスタックを表示 |
| **ExecTrace** | 実行した行の一覧と、各行での変数値 |
| **Trace** | 行×変数のマトリクス表 |
| **Rec. Tree** | 再帰呼び出しのツリー図 |
| **Arrays** | 配列の内容をボックスで表示 |
| **Memory** | 変数のメモリモデル（スタック/ヒープ） |
| **Subst** | 関数呼び出しの「置換モデル」展開 |

## ウォームアップについて

最初の 10 分は「**[Warm-up] Factorial (loop)**」サンプルを使って、ツールの操作に慣れましょう。

やってみてほしいこと:
- `h` キー（Human Step）で進めながら、`result` の値がどう変わるかを追う
- いくつかのタブを切り替えて、好きな表示形式を探す
- スライダーを左右に動かして、実行の好きな時点に戻る

**うまく使えなくても構いません。** ウォームアップの目的は「ツールの存在に慣れること」です。
