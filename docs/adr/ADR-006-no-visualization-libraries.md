# ADR-006: 外部可視化ライブラリを使用しない

- **決定日**: 2026-05-25
- **作成日**: 2026-06-14
- **ステータス**: 承認済み

## 背景・課題

再帰ツリー・ライフタイム・制御フロー・オブジェクトグラフといった SVG ビューを実装するにあたり、D3.js や Chart.js 等の可視化ライブラリを採用するかどうかを検討した。

## 決定

DOM + CSS アニメーション + SVG の手動描画で実装する。外部 UI ライブラリは CodeMirror 6（エディタ）のみとする。

## 根拠

- **バンドルサイズ**: D3.js は ~50KB（gzip）。学習ツールとして GitHub Pages から配信するため、小さいバンドルを優先した
- **制御の精度**: トレース cursor との連動（ノードの色・アイコンをステップごとに更新）は、ライブラリのアニメーション機構と干渉することが多い。DOM を直接操作する方が確実
- **依存関係の少なさ**: 教育用ツールとして長期にメンテナンスされることを想定し、外部依存を最小化した
- **学習コスト**: プロジェクトに関わる教員・学生が SVG/CSS を理解しやすい形で実装を追えるようにした

## 結果・影響

- ObjectGraph には Fruchterman-Reingold 力学レイアウト（80反復、冷却率 0.92）を自前実装した
- SVG ビューは静的生成（`init()`）＋属性更新（`update()`）の 2 段階パターンに統一された
- MemoryView の参照矢印は `position: absolute` の SVG オーバーレイ + `requestAnimationFrame` で描画する手法を採用した
