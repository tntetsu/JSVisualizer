# ADR-012: LineTrace の単一ペイン化（ソースパネル廃止・スニペット列に変更）

- **決定日**: 2026-06-04
- **作成日**: 2026-06-14
- **ステータス**: 承認済み（commit `b6b02d1`）

## 背景・課題

LineTrace ビューは「ソースコードパネル」と「変数テーブル」の 2 ペイン構成を持っており、ソースパネルには縦スクロール同期・ドラッグリサイザー（`jsv-lt-src-w`）が実装されていた。しかし:

- ソースコードはすでに左側の `code-view`（常時表示）で見えており、LineTrace に再度表示するのは冗長
- 2 ペインにするとビューが横に広がり、変数テーブルの可視列数が減る
- コードを見ながらトレース表を見るためにスクロールを同期させる複雑な実装が必要だった

commit `af0d001` (2026-05-26) で最初の単純化（ソース列削除・行高さ統一・スクロール同期実装）を行ったが、まだソースパネルは残っていた。2026-06-02 の v0.8 で 2 ペイン構成を改めて導入したものの、2026-06-04 に最終的に廃止した（commit `b6b02d1`）。

## 決定

ソースパネルを削除し、行番号列に「行番号数字（`.lt-lineno-num`）」と「コードスニペット先頭 15 文字（`.lt-lineno-snippet`）」を表示する単一ペイン構成にする。

```html
<td class="lt-lineno">
  <span class="lt-lineno-num">7</span>
  <span class="lt-lineno-snippet">sum += arr[i]</span>
</td>
```

関連して `jsv-lt-src-w` の localStorage キーと、`#srcPanel` / `#srcLines` / `#setupScrollSync` / `#setupSrcResizer` も削除した。

## 根拠

- スニペット 15 文字でも「何をしている行か」の識別には十分
- シンプルな単一ペインにより横幅を変数テーブルに最大限使える
- ソースコードは常に左の `code-view` が担当するという役割分担が明確になった

## 結果・影響

- `LineTrace` のコードが大幅に簡略化された（スクロール同期・リサイザーロジック削除）
- `localStorage` から `jsv-lt-src-w` キーが廃止された
- 後継の `ExecTrace`（実行トレース）も同じ思想でコードスニペット列を持つ設計になった
