# ADR-047: 制御フロービューを横スクロールできるようにする

## ステータス

採択済み（2026-10-30）

## コンテキスト

制御フロービュー（V-12、`src/views/control-flow/`）は、`if` の true／false を左右の列に並べ、`else if` を false 側の列の中に入れ子にして描く。`else if` を何段もつなげると、入れ子のたびに列が右へ細くなる。

スコープの枠（`.cf-scope`）はビューの幅に固定され、`overflow: hidden` だった。そのため、中身がビューの幅を超えると右端が切り取られ、外側の `.cf-wrap` に `overflow: auto` があってもスクロールできなかった。たとえば FizzBuzz（`else if` が 2 段）を幅 1280px の画面で表示すると、最も右の `console.log(i)` が途中で切れていた。

また、現在のノードへのスクロールは `scrollIntoView({ block: 'nearest' })` で行っていた（`inline` は既定の `'nearest'`）。この方法では、表示幅より広いノード（スコープいっぱいに広がる文など）に対して右端を見せようとして横にずれ、スコープの枠の左側が隠れる。

## 決定

1. **スコープの枠を中身の幅まで広げる**（`web/style.css`）: `.cf-scope` を `width: max-content; min-width: 100%` にし、`overflow: hidden` を外す（角丸は見出し `.cf-scope-hdr` の上側の角に付け直す）。中身がビューより狭ければ従来どおりビューの幅いっぱいに広がり、広ければ `.cf-wrap` の `overflow: auto` で横スクロールする
2. **現在のノードへのスクロールを自前で計算する**（`ControlFlow#scrollToNode()`）: `.cf-wrap` の表示範囲とノードの位置から、縦横のスクロール量を求めて `scrollBy()` する
   - 左（上）に隠れていれば、左端（上端）を余白 24px を残して見せる
   - 右（下）に隠れていれば、表示範囲に収まる大きさのノードのときだけ右（下）へ寄せる。収まらないノードは左端（上端）を優先して動かさない

## 結果

- 入れ子の深い `else if` でも、ノードが切れずに横スクロールで見られる。ステップを進めると、右の奥にあるノードが実行されるときは自動で右へ、戻るときは左へスクロールする
- 中身がビューに収まる場合は、表示は従来と変わらない（true／false の列はこれまでどおり等分の幅）
- 列の幅が中身に合わせて決まるようになったため、ラベルが `…` で省略されにくくなった（省略の上限 `MAX_LABEL = 46` 文字は従来どおり）

## 代替案

- **入れ子が深いときは縦に並べ直す**: 不採用。`else if` の連鎖を縦に並べると、「前の条件の false 側の中にある」という入れ子の関係（このビューで見せたいこと）が見えなくなる
- **文字を小さくして収める**: 不採用。段数に上限がないので、いずれ読めなくなる
