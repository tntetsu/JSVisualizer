# ADR-054: 配列の undefined の要素を「—」で示し、配列ビューに意味を添える

## ステータス

採択済み（2026-11-16）

## コンテキスト

メモ化の題材（`const memo = []; … memo[n] = …`）では、値を入れていない 0〜2 番が `undefined` になる。配列ビューと実行トレースの図は、マスに `undefined` を文字のまま入れていたので、マスの幅で切れて「defin」と表示されていた。

## 決定

- 配列の図（`renderArrayGrid()`。配列ビューと実行トレースで共通）では、`undefined` の要素を薄い「—」で示し、`title="undefined"` を付ける。`null` や `0` はこれまでどおり値を書く
- 配列ビューでは、実行中に一度でも `undefined` の要素があった配列に、「「—」の要素は undefined（値が入っていない）です」と箱の下に添える。ステップによって出たり消えたりするとマス目の位置が動くので、実行全体で判定する
- 実行トレースの小さな図には説明を添えない。同じ行の変数の列に `[undefined, undefined, …]` と出るので、そこで意味がわかる。行ごとに説明を入れると表が読みにくくなる

## 影響

`undefined` の要素がない配列は、表示が変わらない（比較用の題材 14 本の配列ビュー・実行トレースの画面を、修正の前後で画素単位で比べて確かめた）。
