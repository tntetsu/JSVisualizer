# ADR-044: 「代入展開」タブの名前を「置換」に変える

## ステータス

採択済み（2026-10-19）

## コンテキスト

`subst` ビュー（V-02c、SubstTrace）の日本語のタブ名は「代入展開」だった。このビューは、関数呼び出しを `fib(5)` → `fib(4) + fib(3)` → … のように、その関数の return 式（引数を値に置き換えたもの）で置き換えていく過程を表示する。いわゆる置換モデル（substitution model）である。

しかし「代入」は JavaScript では `x = 1` のような変数への代入（assignment）を指す用語であり、このビューが表す内容とは関係がない。英語の「Subst（substitution）」の訳としても不自然で、学習者に「代入文を展開するビュー」と誤解させるおそれがある。

## 決定

日本語のタブ名を「**置換**」に変える（`src/app.js` の `switcher.register('subst', { ja: '置換', en: 'Subst' }, ...)`）。

- 置換モデル（substitution model）の「置換」で、英語の「Subst」と対応する。ビューの説明文はもともと「置換モデル（関数呼び出しを等価な式に置き換えること）」と書いており、タブ名と説明文の用語が揃う
- ビューID（`subst`）は変えない。BhvVisualizer の推奨初期ビュー（URLクエリ `view=subst`、ADR-036）やログの `view` イベントの値はそのまま使える
- 利用者向けマニュアル（`web/manual.html`）の表記を改め、スクリーンショットを撮り直す

BhvVisualizer 側（教員画面の推奨初期ビューの選択肢・学生向けマニュアル・ヒント文）も同じ名前に揃える（ADR-041: 両マニュアルの操作説明は共通）。

## 結果

- タブ名・マニュアル・README・CLAUDE.md・機能仕様書（V-02c、1.18）・設計書の表記が「置換」になった
- 過去の改訂履歴の記述と ADR-014 の記述（「代入展開」）は当時の名前として残した

## 代替案

- **「置換モデル」**: 意味は最も正確だが、他のタブ名（「式評価」「配列」など）より長い。説明文で「置換モデル」と書いているので、タブ名は「置換」で足りる
- **「展開」**: 「代入」の誤解はなくなるが、何を展開するのかが分からず、英語の「Subst」とも対応しない
