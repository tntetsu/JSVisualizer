# ADR-041: 利用者向けマニュアル（日英）とヘッダーの使い方ボタン

## ステータス

採択済み（2026-09-29）

## コンテキスト

JSVisualizerの操作方法は、READMEの「特徴」節（開発者・研究者向けの機能一覧）にしか書かれていなかった。
ステップ実行の4つの粒度の使い分け、3層のハイライトの意味、12種類のビューの読み方などを、
プログラミング学習者がそのまま読める形で説明した資料はなかった。

一方、BhvVisualizer（別リポジトリ）では、授業で配布する学生向けマニュアル（`BhvVisualizer/web/manual.html`）に、
JSVisualizerの画面（「コード実行画面」と呼ぶ）の操作をスクリーンショット付きで詳しく書いた。
これをJSVisualizer単体の利用者にも見せたい、という要望があった。

## 決定

1. **利用者向けマニュアルを `web/manual.html`（日本語）・`web/manual.en.html`（英語）として置く。**
   GitHub Pagesで `https://tntetsu.github.io/JSVisualizer/manual.html` として配信される（`web/` がそのまま配信対象）。
   内容はBhvVisualizerの学生向けマニュアルのコード実行画面の部分をもとに、単体利用向けに書き直した
   （サンプルの選び方・自分のコードの書き方・共有リンク・10,000ステップの上限・設定パネルのSession Logなどを追加し、
   BhvVisualizer固有のログイン・演習一覧・操作ログの記録の説明は含めない）。
   可視化ビューは、論文 IS-26-049 の表1に基づく2軸分類（README・機能仕様書3.2節と同じ）で整理した。
2. **スクリーンショットは `scripts/capture-manual-screenshots.mjs` で撮り直せるようにする。**
   `web/` をその場で配信し、組み込みサンプルを使って日本語表示・英語表示それぞれの画面を
   `web/manual/ja`・`web/manual/en` に保存する。タブは表示名ではなく `data-view` のIDで指定するので、表示言語に依存しない。
3. **ヘッダー右上に使い方ボタン（`#btn-help`、「?」）を置き、表示言語に合わせたマニュアルを別タブで開く。**
   リンク先は `applyI18n()` で `manual.html` / `manual.en.html` を切り替える。
4. **BhvVisualizerから `init` ハンドシェイクを受け取ったら、使い方ボタンを取り除く（`# BHV:`）。**
   BhvVisualizerは学習者にJSVisualizerの存在を意識させない方針で、独自の学生向けマニュアルを持つため。
   ADR-040（評価実験用UIの除去）と同じ箇所・同じ方式で行う。

## 検討した代替案

- **BhvVisualizerの学生向けマニュアルと操作説明を共通化する**（共通のHTML断片を両方に組み込むビルド手順を作る）:
  2つのリポジトリにまたがる仕組みになり手間がかかるため見送った。操作説明は両方に重複するので、
  画面を変えたときは両方のマニュアルを直す必要がある（各マニュアルの冒頭コメントに明記）
- **BhvVisualizerのマニュアルからJSVisualizerのマニュアルへリンクする**: 学生にJSVisualizerの名前が見えてしまうため不採用
- **マニュアルをREADMEに統合する**: READMEは開発者・研究者向けの内容（インストール、URLクエリのAPI仕様など）が中心で、
  学習者向けの説明を混ぜると双方にとって読みにくくなるため、別ページにした

## 安全性の担保

- `verify-bhv-hook.mjs` に3件追加（計19件合格）
  - スタンドアロン起動では使い方ボタンが `manual.html` を指す
  - 英語表示に切り替えると `manual.en.html` を指す
  - `init` 受理後は使い方ボタンが取り除かれる
- マニュアルは幅375pxの表示でも横にはみ出さず、画像がすべて読み込まれることを確認した

## 結果

JSVisualizer単体の利用者は、画面右上の「?」から日本語・英語のマニュアルを開ける。
BhvVisualizerの学習者には、このボタンは表示されない。
