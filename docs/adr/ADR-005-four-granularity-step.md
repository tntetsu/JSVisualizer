# ADR-005: 4 粒度ステップシステム

- **決定日**: 2026-05-25（2 粒度で開始）、2026-05-25（4 粒度に拡張・2行レイアウト確定）
- **作成日**: 2026-06-14
- **ステータス**: 承認済み

## 背景・課題

初期実装ではステップ粒度として「式単位（cursor ±1）」と「文単位（stepOver）」の 2 種類を提供していた。しかし学習者が使うと「細かすぎて追えない」「粗すぎて変化を見逃す」という両極端の問題があった。また関数を丸ごとスキップしたいケースや、人間がトレース表に書くような粒度で動かしたいケースへの対応が必要だった。

commit `81b6e19` (2026-05-25) で粒度セレクターを廃止し expr/stmt の 2 ボタンに変更。
commit `fe19afb` (2026-05-25) で 4 粒度 2 行レイアウトに拡張。

## 決定

以下の 4 粒度を 2 行×4 列グリッドのボタンで提供する。

| 粒度 | API | キー | 説明 |
|------|-----|------|------|
| 式評価 | `cursor ± 1` | `←`/`→`, `b`/`n` | すべての AST ノードの enter/exit |
| 文評価 | `stepOver()` → `matchIdx` | `V`/`v` | サブ式をスキップして文単位 |
| 人にやさしい単位 | `humanStep()` / `humanStepBack()` | `H`/`h` | 代入・条件判定・関数呼び出し等の意味的変化点 |
| 関数呼び出し単位 | `callDepth` 変化まで cursor を移動 | `F`/`f` | 関数 1 呼び出しをひとまとまりに |

```
⏮ │ ◀◀文  ◀式  ▶式  ▶▶文 │ ⏭
   │ ⏪関  ◁人  ▷人  ⏩関 │
```

ボタン色: 細粒度（式・人）= アクセントブルー、粗粒度（文・関数）= グレー

## 根拠

- **「人にやさしい単位」** は初学者が紙でトレース表を書くときの停止点と一致させることで、教員が「1ステップ進めて」と言ったときの直観と合う
- **「関数単位」** は関数の中身を飛ばしたい上級者向け
- キーボードショートカットを整理することで、マウスを使わず両手でステップ操作できる

## 結果・影響

- `StepController` クラスが 4 粒度のメソッドを統一 API として提供
- `humanStep` の定義（どの AST ノードで停止するか）が重要な設計変数となり、後に度々見直された（ADR-008 参照）
