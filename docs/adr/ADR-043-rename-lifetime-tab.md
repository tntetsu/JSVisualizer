# ADR-043: 「変数寿命」タブの名前を「ライフタイム」に変える

## ステータス

採択済み（2026-10-09）

## コンテキスト

`lifetime` ビュー（V-11）の日本語のタブ名は「変数寿命」だった。このビューは、横を時間、縦を呼び出しの深さとして、それぞれの関数の呼び出しがいつ始まっていつ終わったかを帯で表示する。帯には関数名・引数・その呼び出しの変数の値が書かれる。

BhvVisualizer連携で使う「ソフトウェア基礎論」第3回の課題（関数の入れ子呼び出しで、関数が呼び出される順番と終了する順番を問う）のヒントを検討した際、コールスタックよりこのビューの方が、呼び出しと終了の順番が一目で分かることが分かった。ところが、この課題の関数（`first`・`second`・`third`）はローカル変数を持たない。帯が表しているのは変数の寿命ではなく関数の実行の区間であり、「変数寿命」というタブ名では学生にとって違和感がある。

もともとこのビューは、変数の寿命だけでなく関数の実行の寿命（フレームの存在区間）を表している（[design.md](../design.md)「`lifetime/` — コールスタック時系列のフレームグラフ」）。英語のタブ名はすでに「Lifetime」で、変数に限定していない。

## 決定

日本語のタブ名を「**ライフタイム**」に変える（`src/app.js`の`switcher.register('lifetime', { ja: 'ライフタイム', en: 'Lifetime' }, ...)`）。

- 「変数」を含まないカタカナ語にし、関数の実行の区間と、その引数・ローカル変数の区間の両方を指せるようにする。英語の「Lifetime」とも対応する
- ビューID（`lifetime`）は変えない。BhvVisualizerの推奨初期ビュー（URLクエリ`view=lifetime`、ADR-036）やログの`view`イベントの値はそのまま使える
- ビューの上に出る説明文（日本語）を「関数の呼び出しがいつ始まりいつ終わるかを、呼び出しの深さごとの帯で表示します。帯には引数やローカル変数の値も表示されます。」に改める（旧: 「…引数やローカル変数の生存期間がわかります。」）
- 利用者向けマニュアル（`web/manual.html`）の説明も「関数の実行や、その引数・ローカル変数がいつからいつまで続くかが分かります」に改め、スクリーンショットを撮り直す。英語版（`web/manual.en.html`）は表記が変わらないが、画像は同じスクリプトで撮り直される

BhvVisualizer側（教員画面の推奨初期ビューの選択肢・学生向けマニュアル）も同じ名前に揃える（ADR-041: 両マニュアルの操作説明は共通）。

## 結果

- タブ名・マニュアル・README・CLAUDE.md・機能仕様書（V-11、1.17）・設計書の表記が「ライフタイム」になった
- 過去の改訂履歴の記述（「変数寿命」）は当時の名前として残した

## 代替案

- **「変数寿命」のまま、マニュアルで関数の実行も表すと説明する**: 不採用。タブ名だけを見て使う学生には伝わらない
- **「関数の寿命」「呼び出しの寿命」など**: 不採用。今度は引数・ローカル変数の区間を表していることが伝わりにくい。英語の「Lifetime」と対応するカタカナ語の方が両方を含められる
